## skm plugin

Manage installed provider/target plugins

### Synopsis

Install a local plugin executable into ~/.config/skm/plugins, list what is
installed there, and remove one again — instead of symlinking by hand.

A plugin is linked, not copied, so edits in your own checkout take effect
immediately.
