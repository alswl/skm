# skm TUI Wireflows

基线为 [PR #5 的 `6ca5bb6`](https://github.com/alswl/skm/pull/5/commits/6ca5bb68ce4a02fe64cbe8c92b2e61aeb15c3792)。下面是当前界面的低保真草图。方括号内是用户能看到的页面或弹窗，以及决定下一步的字段。箭头前是操作，箭头后是目的地。示例技能用 `review`，示例目录用 `api`。

| 常驻 Page | 主要内容 | 从哪里进入 |
|---|---|---|
| 技能库 | 来源标签页、搜索、技能及安装状态 | 启动 skm |
| 技能详情 | 内容、来源、实际安装位置 | 技能库 `Enter` |
| 目录 | 用户级与已登记目录、标签、扫描结果 | 技能库或目标设置 `M` |
| 用户级目标设置 | 目标名称、客户端、路径、支持类型 | 技能库 `t` |
| 任务队列 | 任务名、运行状态、完成结果 | 技能库 `J` |

选择框用 `j/k` 移动，复选框用空格切换，`Enter` 提交。确认页用 `y` 或 `Enter` 执行，用 `Esc` 取消。选择过程中取消会退出当前步骤，回到承载该操作的页面。

## 模块与优先级

模块按用户目标划分，和上面的 Page 是两层结构。例如「安装」可以从技能库、详情和目录发起。「安装声明」也在目录页操作，但有独立的确认和写入规则。

- **P0 · 核心路径**。优先评审入口、步骤和结果反馈，并保留实操证据。
- **P1 · 配套路径**。覆盖首次配置、维护、恢复和安全清理。涉及删除或卸载的确认保护仍是必需的。
- **P2 · 进阶操作**。集中放在操作菜单或辅助页面，按需展开。

这里的优先级用于评审和验收排序。各项实现和实操状态另见文末证据。

| 模块 | P0 核心 | P1 配套 | P2 进阶 |
|---|---|---|---|
| 技能库 | 浏览、搜索与详情 | 导入、更新（单项与批量） | 发现外部技能并收编、整理技能库 |
| 安装 | 用户级安装、从技能发起计划、按目录或标签批量安装 | | |
| 目录管理 | 发现登记、路径与标签、扫描和收录 | | |
| 安装声明 | | 恢复安装、撤回声明、卸载链接 | |
| 用户级目标 | | 设置客户端目标 | |
| 后台任务 | | | 查看和处置任务 |

## 模块一 · 技能库

### 1. [P0] 找到技能并查看详情

```text
[技能库  来源标签页 | / 搜索 | 名称 · 类型 · 状态]
  Tab 切来源，/ 搜索，. 显示或隐藏归档
  选中 review，Enter
    → [详情  review | 内容 · 来源 · 安装位置]
       j/k 滚动，R 刷新，Esc 返回技能库
```

### 2. [P1] 导入技能或命令

```text
[技能库] m → [地址输入  本机路径或远程地址]
  Enter → [选择来源  自动 / 指定来源]
  Enter → [选择类型  自动 / skill / command]
  Enter → [技能库  导入任务及结果]
```

来源和类型可由地址推断并预选。遇到同名冲突时，按提示确认是否覆盖。任务结果也可在队列查看。

### 3. [P2] 发现外部技能并收编

```text
[技能库] o → [发现结果  技能名 · 客户端路径]
  空格勾选，Enter → [技能库  收编结果]
  空格勾选，d → [确认删除外部内容] → [技能库  删除结果]
```

扫描不到外部技能时，在技能库显示提示。这里发现的是已有技能。目录页的发现操作搜索 Git 仓库。

### 4. [P1] 更新单个技能或批量更新

```text
[技能库 / 详情  review] p → [原页面  更新任务及结果]

[技能库  当前来源与搜索结果] P
  → [确认批量更新  条目数量与范围]
  → [技能库  更新任务及结果]
```

只有可从来源更新的条目参与。批量更新受当前来源与搜索范围约束。

### 5. [P2] 整理技能库

```text
[技能库 / 详情  review] x → [操作菜单  只显示适用的动作]
  归档 → [确认归档并卸载] → [技能状态更新]
  恢复归档 → [技能状态更新]
  删除 → [永久删除确认] → [技能库  条目移除]
  规范化 → [选择来源] → [移动预览] → [条目更新]
  认领 → [技能按本地自建条目处理]
  修复 → [冲突或失效链接预览] → [确认后执行]
  创建 Fork → [详情或列表  active+fork]
  替换 / 丢弃 Fork → [确认处理本地副本] → [条目更新]
```

归档会先卸载现有受管安装。移动或删除受安装声明和 Fork 状态的保护，界面会报告阻塞原因。

## 模块二 · 安装

### 6. [P0] 管理当前技能的用户级安装

```text
[技能库 / 详情  review] i
  → [User Installs  目标名 · 安装状态 · 复选框]
  空格调整，Enter
    → [应用变更] 或 [确认移除或覆盖] → [原页面  结果]
```

这是原有的直接安装面板。复选框表示每个用户级目标的期望状态。变更作用于本机安装。

### 7. [P0] 从当前技能发起声明式安装

```text
[技能库 / 详情  review] I
  → [安装范围  用户级 / 目录标签]
     用户级   → [选择用户级客户端目标]
     目录标签 → [选择标签  team · 命中数量] → [选择客户端]
  → [安装预览  范围 · 待装 / 已装 / 阻塞]
  → [目录  执行结果与刷新后的安装]
```

`I` 带入当前技能。这个入口目前没有任意已登记目录的选择器。要精确安装到一个目录，可以走第 8 条动线。

### 8. [P0] 从目录发起一个或多个技能的安装

```text
[目录  user | › api · team] i
  → [多选技能  □ review · □ lint]
  → [安装范围  用户级 / 标签 / 当前目录 api]
  → [标签范围才出现  多选标签 · 各自命中数量]
  → [多选客户端  目录级示例 □ Codex · □ Claude Code]
  → [安装预览  范围 · 数量] → [目录  执行结果]
```

标签命中取并集，同一安装位置只执行一次。第 7、8 条共用同一预览。按 `d` 展开路径和状态。若有链接会出现在 `git status`，预览默认跳过这些位置。按 `g` 将它们纳入新预览，再确认。过期计划需要重新预览，部分成功会逐项报告。

## 模块三 · 目录管理

### 9. [P0] 发现和登记目录

```text
[技能库] M → [目录  user · 已登记目录]
  a → [输入搜索根目录] → [勾选已发现的 Git 目录]
  Enter → [目录  选中第一项新登记目录]
```

没有新目录时显示提示。若标签筛选仍生效，清除筛选后可看到未打标的新目录。新登记目录可以继续打标、收录实际安装或发起安装计划。

### 10. [P0] 设置目录路径、打标和筛选

```text
[目录  › api · team] x → [目录操作]
  p 设置本机路径 → [路径输入] → [目录  重新扫描]
  t 编辑当前标签 → [标签输入] → [目录  更新标签]
  T 批量打标 → [多选目录] → [标签输入] → [目录  更新标签]
  f 按标签筛选 → [标签输入] → [目录  匹配列表]
```

标签输入默认添加，前缀 `-` 表示移除。路径和标签会改变后续计划的范围。已有链接在这些动作完成后仍留在磁盘上。

### 11. [P0] 扫描和收录现有链接

```text
[目录  user | › api · team] 移动选择或按 r
  → [扫描中] → [客户端 · 安装状态 · 技能] / [无结果] / [错误]

[目录  codex · installed (undeclared) · review] Enter
  → [选择收录  客户端 · 技能 · 路径]
  → [收录确认] → [目录  已声明的安装]
```

切换范围会发起新扫描，迟到的结果不会覆盖当前选择。收录要求链接匹配库内技能，确认后写入声明，保留原链接。

## 模块四 · 安装声明

### 12. [P1] 恢复声明中的安装

```text
[目录  已设置相关目录的本机路径] R
  → [恢复预览  位置数 · 声明数 · 阻塞 · 声明外安装]
  d 查看明细 → 确认 → [目录  执行结果]
```

路径缺失或有冲突时会报告原因。恢复会补齐可执行的声明位置，声明外链接保留。

### 13. [P1] 撤回声明和卸载链接

```text
[目录] d → [选一条声明  技能 · 客户端 · 范围]
  → [确认撤回] → [目录  声明已撤回，链接保留]

[目录  选定用户级或目录级范围] u
  → [选一个链接  客户端 · 技能 · 路径]
  → [核验覆盖和链接] → [确认卸载] → [目录  链接已移除]
                       → [阻塞原因]
```

链接仍被其他声明覆盖、无法核验或文件系统能力不足时会阻塞卸载。两条动作都能从目录页的 `x` 菜单进入。

## 模块五 · 用户级目标

### 14. [P1] 设置客户端目标

```text
[技能库] t → [目标设置  名称 · 客户端 · 支持类型 · 路径]
  a → [名称] → [客户端] → [路径] → [支持类型与策略] → [目标列表]
  Enter → [编辑当前目标的路径] → [目标列表]
  d → [确认移除目标配置] → [目标列表]
  M → [目录页]
```

移除目标配置后，已安装内容仍在原位置。配置目标后，可以回技能库用 `i` 管理实际安装，或用 `I` 发起声明式计划。

## 模块六 · 后台任务

### 15. [P2] 查看和处置后台任务

```text
[技能库  导入、更新等后台任务] J
  → [任务队列  ID · 状态 · 任务名]
     c 取消选中任务，C 取消全部，x 清除已完成
  Esc / J → [技能库]
```
